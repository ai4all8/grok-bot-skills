# grok-bot-skills

Skills for Grok Bots. Download a `.skill` file and install it in Grok Bot.

| Skill | Download | What it does |
|---|---|---|
| Imagine | [imagine.skill](https://github.com/ai4all8/grok-bot-skills/raw/main/imagine.skill) | Generate or edit images and make short videos with xAI Grok Imagine, using your own SuperGrok / X Premium+ sign-in (OAuth, no API key). |
| Video Download | [video-dl-v3.skill](https://github.com/ai4all8/grok-bot-skills/raw/main/video-dl-v3.skill) | Download videos from YouTube, Instagram, Threads (no login), TikTok, Facebook, X and most other sites. |
| Grok TTS | [grok-tts-v1.skill](https://github.com/ai4all8/grok-bot-skills/raw/main/grok-tts-v1.skill) | Make narration audio files (WAV/MP3) with Grok text-to-speech. Cantonese by default. Shares Imagine's sign-in. |

All scripts are Python 3.9+, standard library only. Downloaded videos belong to their creators; re-uploading needs the owner's permission.
